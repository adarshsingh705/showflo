Security

Last updated August 2026

Security isn't a feature we bolt on — it's how showflo is built, from the first line of code.

Security philosophy

We design for the assumption that deal data is sensitive by default. Every room, signal, and document is handled with the same rigor buyers already expect from the tools they trust.

Encryption

Data is encrypted in transit with TLS 1.2+ and at rest with industry-standard encryption. Access to production systems is limited to the people and services that need it to operate showflo.

Access Control

  • SSO support, so access follows your identity provider.
  • Granular, role-based permissions inside every room.
  • Full audit logging of who viewed what, and when.

Responsible Disclosure

Found a vulnerability? We want to hear about it. Report it to the address below and we'll respond promptly — we ask that you give us reasonable time to address the issue before any public disclosure.

Contact

Report a security issue: security@showflo.in
