# Showflo V1 - Product Strategy & Daily Engagement Plan

> **Vision:**  
> Showflo is **not** a Property Presentation Builder.  
> Showflo is a **Sales Presentation & Buyer Engagement Platform** that helps professionals present anything beautifully and close more deals.

---

# Core Philosophy

Don't build a product for real estate.

Build a product for **selling anything**.

Supported industries:

- 🏠 Property
- 🚗 Cars
- 🛋 Furniture
- ☀ Solar
- 💼 Services
- 📦 Products
- ✨ More in future

The core product remains exactly the same.

Only templates and content change.

# The Biggest Problem

Presentation builders are not daily-use products.

If users only create presentations,
they will visit twice a month.

Eventually they cancel.

So Showflo needs daily value.

# How Analytics Work

Users do NOT enter these numbers.

Showflo tracks everything automatically.

Workflow

```
Client opens

showflo.in/@adarsh/luxury-villa

↓

Frontend loads

↓

POST

page_view

↓

Database saves event
```

Examples

Page View

```
event = page_view
```

Gallery

```
event = gallery_view
```

Pricing

```
event = pricing_view
```

CTA

```
event = cta_click
```

Download

```
event = brochure_download
```

Lead

```
event = lead_submit
```
